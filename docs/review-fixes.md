# 기록 보존·복사·가져오기 규칙

- 저장 전에 백업 읽기와 동일한 스키마로 검증합니다. 텍스트 필드별 최대 20,000자이며, 실패하면 현재 입력과 기존 기록·이력을 보존합니다. 구형 통증 표시의 기존 호환 변환은 유지합니다.
- 차트번호가 다르면 이름·생년월일이 같아도 합치지 않습니다. 새 기록에서 복사된 환자 ID와 식별정보가 충돌하면 별도 환자로 저장합니다. 기존 기록의 환자 변경은 차단합니다. 같은 차트번호를 유지한 이름·생년월일 정정은 가능합니다.
- 같은 환자 복사: 환자정보와 임상 내용 전체(평가, 계획, 치료 후 NRS 포함)를 복사합니다. 기록 ID, 저장시각, 작성·수정자, 담당자, 작성일은 새 기록 기준으로 초기화합니다.
- 다른 환자용 복사: 임상 문구는 유지하고 환자 ID·이름·차트번호·생년월일·성별 및 통증 점수·부위를 비웁니다. 다른 환자에게 임상 내용이 적절한지 확인한 후 저장하세요. 복사된 배열은 원본과 독립적입니다.
- ‘이 초안 삭제’는 선택한 항목만 삭제합니다. 목록 표시 이후 새로운 입력으로 해당 키가 갱신되었으면 삭제를 중단합니다. 저장 성공 후 현재 초안 정리와 분리되어 있습니다.
- 백업 수정 이력은 삭제된 기록 및 이미 존재하는 기록의 이력도 가져옵니다. 원본 이력 ID와 기록 ID로 중복을 방지하며, 가져온 시각·관리자와 작성자 미검증 표시를 보존합니다. 잘못된 이력은 가져오기를 중단합니다.
- 같은 로그인 ID의 서로 다른 UID는 자동 합치지 않습니다. 충돌 계정과 알 수 없는 담당자는 로그인 불가능한 ‘미배정’ 계정으로 보존합니다. 관리자 → 치료사 관리 → 목록 → 미배정 치료사에서 실제 담당자를 확인한 뒤 ‘기록 배정’을 누르세요. 이관 시 최초 작성자와 이력을 유지합니다.

회귀 검증: 길이 경계와 저장 실패 원본 보존, 차트 충돌, 복사 후 환자 변경, 삭제 기록 이력 및 반복 가져오기, 계정 충돌과 명시적 배정, 초안 삭제 화면 동작, 임상 복사 필드와 원본 독립성을 테스트합니다.
