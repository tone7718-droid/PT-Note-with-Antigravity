# 저장 정책·임상 데이터·접근 통제 (5~9번)

## 현재 동작

- 세 앱 모두 새 기록과 기존 기록의 입력 변경을 **5초 주기로 암호화된 임시 초안에만 저장**합니다. 실제 기록과 수정 이력은 ‘새 노트 저장/수정 저장’ 버튼으로 반영합니다.
- 환자 전환·새 기록 작성·백업 가져오기/복원 전에 초안 저장을 기다립니다. 저장 실패 시 해당 화면 전환을 중단하고 오류를 표시합니다. 로그아웃은 초안 저장을 시도하고 실패를 알린 뒤 세션을 닫습니다.
- 재실행·재로그인 후 해당 기록을 열면 이전 초안을 선택해 복구할 수 있습니다. 계정·기록·탭별로 분리해 다른 사용자의 초안을 표시하거나 덮어쓰지 않습니다. 구버전의 작성자 없는 공용 초안은 관리자만 확인·복구할 수 있으며 자동 삭제하지 않습니다.
- 브라우저 숨김 시 추가 저장을 시도하며, 아직 임시 저장되지 않은 변경이 있으면 종료 경고를 요청합니다. OS 강제 종료·전원 차단 직전의 마지막 5초 입력까지 보장하지는 않습니다.
- 오래된 초안을 복구해도 당시 기록 버전을 유지합니다. 다른 창에서 그 뒤에 기록을 수정했다면 기존 충돌 검사가 저장을 막습니다.

## 수정 이력

최초 작성자(`createdBy/createdAt`), 마지막 수정자(`updatedBy/updatedAt`), 현재 담당자(`therapist/therapistUid`)를 분리합니다. 이관 시 최초 작성자를 바꾸지 않습니다. 기능 도입 전 기록의 최초 작성자는 추정하지 않고 ‘확인 불가’로 표시합니다.

기록 저장·이관·삭제·가져오기·복원 시 작업자, 시각, 필드별 이전/이후 내용을 암호화된 `pt_record_history_v1`에 추가합니다. 기록과 이력을 하나의 복구 저널로 함께 반영하므로 이력 저장 실패 시 기록도 되돌립니다. 최근 5개 자동 백업과 달리 이력은 자동으로 오래된 항목을 삭제하지 않습니다. 공간 부족 시 기록 변경이 중단될 수 있으므로 백업과 저장 공간 관리가 필요합니다.

기록 화면의 ‘수정 이력 조회’에서 확인할 수 있습니다. 관리자용 백업 내보내기에도 이력을 포함합니다. 새로 가져온 기록의 외부 이력은 ‘백업에서 가져온 이력·작성자 미검증’으로 구분합니다. 이력은 현재 로컬 저장소에서 보존되며, 위변조 방지 서버 감사 로그나 전자서명을 대신하지 않습니다.

## ROM·통증 추이

자유 입력 원문을 유지하면서 관절, 운동 방향, 좌우, AROM/PROM, 시작각·끝각을 별도로 저장합니다. 기존 관절명에 방향·좌우가 들어 있어도 자동 추정하여 분해하지 않습니다. 새 구조 필드는 사용자가 지정합니다.

- `20~100` → 시작각 20, 끝각 100의 두 값으로 표시.
- `120°` → 끝각 120만 표시. 시작각 0을 추정하지 않음.
- `90/120`, 숫자 뒤 임의 문자열 → 원문 표에는 남기고 그래프에서는 제외.
- 동일한 관절·방향·좌우·측정 방식이 한 기록에 여러 번 있으면 첫 값만 고르지 않고 해당 시점 그래프를 제외.
- 구조화된 각도를 입력하면 해당 각도를 우선 사용. 누락값을 0으로 바꾸지 않음.
- 치료 전·후 NRS를 별도 선으로 표시하며 결측 구간을 연결하지 않음.

## 로컬 접근 통제와 병원 공동 사용의 경계

처음 설치하면 직접 관리자 비밀번호를 설정합니다. 이미 존재하는 계정의 비밀번호를 임의로 변경하지 않습니다. 최초 설정 비밀번호는 8자 이상입니다. 이후 계정 관리 화면에서는 각 앱의 문자/최대 길이 제한도 적용됩니다. 업그레이드 후 다시 로그인해야 합니다.

세션은 탭별 sessionStorage로 분리하고 권한은 현재 계정 레코드에서 읽습니다. 퇴사·비밀번호 변경/재설정 후 이전 세션은 더 이상 사용할 수 없습니다. 계정 변경은 다른 탭의 화면에도 반영합니다.

| 동작 | 관리자 | 일반 치료사 |
| --- | --- | --- |
| 기록 읽기·수정·삭제·이력 조회 | 해당 로컬 병원 범위 전체 | 본인 담당 기록만 |
| 새 기록 작성 | 가능 | 본인 담당으로만 가능 |
| 계정 관리·담당자 이관 | 가능 | 불가 |
| 전체 백업 내보내기·가져오기·복원 | 가능 | 불가 |
| 임시 초안 | 본인 초안 및 구버전 작성자 미상 초안 | 본인 초안 |

병원 범위 식별자는 현재 설치의 로컬 데이터 구분용입니다. **다른 PC와 공유되는 병원 계정이나 서버 권한 체계를 구현한 것은 아닙니다.** 로컬 저장소와 암호화 키에 접근할 수 있는 PC 소유자의 직접 조작을 막지는 못합니다. 병원 공동 사용에는 중앙 인증, 서버의 병원/사용자 권한 검사, DB 트랜잭션·버전 검사, 서버 감사 이력과 백업을 별도로 구축해야 합니다. 이번 변경은 그 서버를 배포하거나 기존 환자 데이터를 외부로 보내지 않습니다.

## 배포

- Progress iOS: `com.ptclinic.progressnote`
- ChatGPT iOS: `com.ptclinic.ptnote3`
- 위 식별자는 각 앱의 Capacitor 설정과 일치합니다. 이전 `com.ptprogressnote.app` 설치와는 별도 앱으로 취급될 수 있으므로 **기존 앱에서 암호화 백업을 내보낸 뒤 새 앱에서 가져오기**가 필요합니다. 기존 앱을 먼저 삭제하지 마세요. iOS 서명/프로비저닝도 새 식별자에 맞게 준비해야 합니다.
- Antigravity Electron 아이콘 `public/favicon.ico`는 현재 Git 추적 파일로 존재합니다. 이를 검사로 확인하며 새 아이콘을 임의로 만들지 않습니다.
- Progress는 빌드 시 Google Fonts 다운로드를 제거했습니다. 한글은 기존 로컬 Pretendard, 고정폭 글꼴은 OS의 로컬 글꼴을 사용합니다.

## 검증 명령

```sh
npm ci
npm test
npx tsc --noEmit
npm run lint
npm run build
npx playwright install --with-deps chromium
npm run test:e2e
```

CI에서 같은 흐름을 실행합니다. E2E는 빌드된 웹앱에 가상 계정을 만들고 초안 저장·재실행·환자 전환·수정 이력·로그아웃 복구를 검사합니다. 실제 환자 데이터는 사용하지 않습니다. 네이티브 서명·설치·업데이트 검증은 별도 플랫폼 환경이 필요합니다.
